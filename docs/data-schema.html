เสร็จแล้ว กำลังจะทำ แผนอนาคต
📊 Dashboard แสดงผล
  • เสร็จ ภาพรวม KPI — จำนวนคน / ไซต์ / ผู้รับเหมา + % คนระดับ 2
  • เสร็จ กราฟจำนวนคนระดับ 2 ต่อ 17 ทักษะ
  • เสร็จ สรุปรายไซต์ & ผู้รับเหมา
  • เสร็จ รายบุคคล — ค้นหา / กรอง / แบ่งหน้า
  • กำลังทำ เลือกดูตาม "รอบ" + เทียบพัฒนาการย้อนหลัง
  • อนาคต Export เป็น Excel / PDF
  • อนาคต ใช้งานบนมือถือได้ (responsive)
🔑 เข้าระบบ & ยืนยันตัวตน
  • กำลังทำ Login ด้วยรหัสพนักงาน 6 หลัก
  • กำลังทำ ต้อง login ก่อนถึงจะเห็น Dashboard
  • กำลังทำ บันทึกว่าใครเข้ามาดู (เวลาเข้าล่าสุด)
  • ทางเลือก ประวัติการเข้าทุกครั้ง (auditLog)
👤 จัดการผู้ใช้ (แอดมิน)
  • กำลังทำ แอดมินสร้าง / แก้ไข / ปิดบัญชีผู้ใช้
  • กำลังทำ กำหนดบทบาท (executive / tts_staff / site_manager / admin)
🔄 นำเข้าข้อมูล
  • เสร็จ นำเข้าจากไฟล์ Excel ที่ HR กรอก
  • กำลังทำ เก็บเป็นรอบ (snapshot) — เก็บประวัติย้อนหลัง
  • อนาคต ดึงจากระบบประเมินภายนอกอัตโนมัติ (Phase 2)
จุดสำคัญ: SiteTalent ไม่ได้เป็นคนประเมิน — เราแค่ ดึงข้อมูลผลประเมินจากระบบภายนอก มาเก็บเป็นสำเนาแล้วทำ Dashboard ให้ดูง่าย ทุกครั้งที่มีการประเมินรอบใหม่ เราจะดึงเข้ามาเป็น "รอบใหม่ (snapshot)" เพื่อเก็บประวัติย้อนหลัง
